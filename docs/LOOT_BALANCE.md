# 掉落与品质曲线验收

日期：2026-10-31。沿用 `generateLoot`、`getLootProfile` 和项目的可重现随机数，没有增加运行依赖。

## 职业权重

- 普通刷本、精英、首领与哥布林：抽到职业专属装备时，当前角色职业占 80%，另外四职业各占 5%。先决定职业，再选装备，避免某职业传奇条目更多造成偏置。
- 普通品质装备与通用传奇不限制职业，不计入上述职业占比。太古保留对应传奇或套装身份，也遵守自然掉落的职业权重。
- 部位秘藏仍定向当前职业或通用装备；首通旅程、实验室与显式指定的套装/传奇保持目标身份。刷到其他职业装备可以存入账号共享仓库留给另一角色。
- 缺件优先继续通过已有 `ownedSetPieces` 接口实现，不另建一套掉落状态。

## 品质平滑引入

原曲线在新品质解锁前已插值出锁定品质权重，随后被归零并重新归一化，导致解锁层突然跳变。现在在每个解锁层的前一层设置明确锚点，新品质从小概率开始上升，层间仍使用原有线性插值。

## 验证与边界

`pnpm exec tsx --test tests/loot-distribution.test.ts`：3 组测试一次通过。覆盖四来源、150 层的概率归一化相关边界、相邻层单品质变化小于 7 个百分点、各品质及以上概率不倒退、新品质首次概率不超过 3%，并覆盖职业统计、秘藏、显式身份及缺件优先。

现有 `learning-loot` 的门槛、奖励与存档回归由最终整体验收统一执行。以上为真实掉落函数的固定种子统计与曲线检查，不等同于玩家数十小时刷装手感、全部 150 层手动通关或商业游戏原版数值复刻。
