# 自然养成角色从百层到登顶需要多久

在同一随机种子、同一整备规则下，15 套流派中有 14 套在百层后的两小时战斗预算内登顶。拉斯玛骨爆最快，6 分 55 秒；暗影利刃用了 84 分 58 秒。荒原狂风打过第 149 层时已经耗尽预算。七套流派能在 15 分钟内从 100 打到 150，同职业的不同流派也有明显落差。

## 实测口径

从一级空装创建角色，使用真实战斗引擎、自然掉落、首通奖励、背包和角色结算。每个流派选择对应的旅程套装；速通可跳层，在首次通过 100 层的结算时开始计时。每次都用已获得的技能点、金币、结晶、碎片和宝石整备。穿戴优先匹配流派传奇、目标套装，再比较基础攻防。目标物品 ID 取自现有流派配置。角色等级、装备和材料全部通过实际结算积累。

每次整备最多消耗 500 碎片做一次定向秘藏十连，优先寻找缺失传奇；得到目标散件时萃取并配置魔盒。分解淘汰装备，优先神铸武器，镶嵌自然获得及合成的红宝石。冲层失败后回刷此前能在 90 秒内通关的最高可选低层三次，再向前挑战。操作策略统一为接近敌人后绕圈、技能自动施放，不主动开圣坛或使用位移。模拟保留了随机敌人与掉落，省去了画面与声音。

## 同职业差距与少用养成系统的影响

- 魔法师的陨石与执政官流派分别用时 13:06、13:59，冰封球用时 46:00，含六次回刷和两次失败。野蛮人的大地裂变用时 14:17，荒原狂风在同一预算内仍差最后一层。
- 部分卡点集中在塔顶。暗影利刃到 140 层用时 15:23，之后又用了 69:35 才登顶；塔格奥毒镰则有 36 次回刷，单是回刷就用了 26:02。
- 第二种子 8817 下，风暴召唤者在 9:32 登顶，荒原狂风在 119:30 登顶。两个种子都显示了这两套的差距，但仅凭这些样本不能给出某个流派的真人通关率。
- 另以种子 7715 对照少用养成系统的情境：关闭脚本的定向十连和魔盒，其余规则照旧。风暴召唤者从 8:30 延长到 91:04，其中 27 次回刷、11 次失败。荒原狂风在 120:33 时最高通关 111 层；使用完整整备策略则在 120:14 时最高通关 149 层。两项功能同时关闭，实验无法分离各自对耗时的贡献。

## 复现

使用项目自带的战斗模拟器。第一个参数是流派 ID，第二个是种子，第三个是百层后的战斗分钟预算。可选模式 `drops` 关闭定向十连与魔盒。每次运行输出一行 JSON，其中回刷时间、百层后总时间及里程碑均以秒计。

```sh
pnpm exec tsx scripts/audit-farming.ts stormcaller 7715 120
pnpm exec tsx scripts/audit-farming.ts wasteland 8817 120
pnpm exec tsx scripts/audit-farming.ts stormcaller 7715 120 drops
```

本轮共保留 19 条自然养成样本。熟悉目标装备、每场都整理背包、持续向敌人靠近等假设会影响时间。普通玩家实际耗时需要另外记录战斗和营地停留时间。[完整原始结果](farming-results.json)
