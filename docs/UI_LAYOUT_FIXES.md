# UI 布局修订记录

手机营地采用全屏可见地图作为默认画面。HUD 浮在地图上，只保留必要操作；不使用遮住场景的总览卡片或地图缩略图。

## 营地 HUD 与地图

- 顶部为约 56px 高的紧凑旅人栏，显示小头像、角色名和等级，并提供按需打开的资源袋与指南按钮。
- 底部操作栏约 64px 高（另计设备安全区），提供装备、技能、出征、旅程和服务。任务、货币详情及各系统按需打开；选择出征后在 `CoopPanel` 内选层或组队。
- 手机地图按可视区域 `cover` 显示；人物目标高度约 58–72px，并独立于地图缩放。PC 与手机均无常驻摇杆：触摸地图时显示浮动摇杆，松手后隐藏；PC 使用点击/拖动和键盘操控。
- HUD 以透明悬浮层呈现，只有按钮及展开的资源浮层接收指针事件，地图仍可直接操作。桌面端底栏限制宽度并居中。

## 系统页与响应式布局

- 角色装备页折叠纸娃娃档案；技能页使用技能树与说明抽屉，保留节点选择上下文；系统切换使用单个分组选择器。
- 系统正文独立滚动，移动端输入字号不小于 16px。紧凑布局断点覆盖 960px 并支持手机横屏；页面高度跟随 `visualViewport`，适配地址栏与软键盘变化。
- 新角色创建引导和角色删除确认流程保留。

## 素材、镜头与焦点

- HD 角色图（512px）、技能施法图（256px 单元）和地面图（1024px 单元）由已有原图恢复。野蛮人施法图的矩形底色另经 ImageGen 编辑清除，源图为 `docs/art/combat-sources/cast-barbarian-clean.png`；不将本轮描述为完全没有 AI 图像编辑。
- 营地镜头按当前视口覆盖场景，去除原始世界尺寸的强制缩放下限，人物显示高度独立于镜头裁切；战斗使用单独的 `combatFraming`。按钮按下使用 CSS `translate`，避免干扰地图元素自身的定位变换。
- 地图背景与大型交互区不显示方框焦点边框，键盘可操作按钮仍保留可见焦点；摇杆保持圆形。

## 验收状态

- 浏览器检查了 390×844、320×480、844×390 和 1280×800 视口：营地地图覆盖完整视口，无页面横向溢出；390px 宽时角色显示框约 70px，320px 宽时约 58px。默认状态没有摇杆 DOM。
- 已走通按需出征选层、进入单人战斗、暂停与返回。390×844 战斗画布覆盖视口，两个已学技能的底栏约 80px 高；未学习技能占位已删除，避免多行占位遮挡地图。
- 操作回归 6 项通过，包含触摸移动 14px 半速、28px 全速、超半径钳位及松手归零；本轮视觉回归与素材透明角检查通过。最终生产构建通过。
- 实际截图见 `docs/art/ui-preview/world-first-*.png`。这里只确认浏览器布局和代码检查；浮动摇杆仍需手机实际触摸反馈，不声称已通过真机帧率或整体手感验收。

## 透明特效编辑记录

模式：ImageGen 编辑既有图片，保留透明背景。输入为已有野蛮人施法图集，输出归档为 `docs/art/combat-sources/cast-barbarian-clean.png`，再由 `scripts/prepare-combat-art.ts` 切分并生成 WebP 图集。

编辑要求：保留八个技能图案及四列两行的排列、颜色和像素幻想风格，清除米色、灰色、白色矩形底色，使背景、角落及单元间隔透明，保持特效本身。其余职业、人物与地面使用已有原图恢复。
