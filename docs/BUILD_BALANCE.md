# 十五流派实测与机制修复

日期：2026-10-31。运行命令：`pnpm exec tsx scripts/benchmark-builds.ts`。

## 方法

复用流派实验室的实际100级、100级太古装备、30级神铸、四件套与三槽魔盒配置；装备随机种子8801、战斗种子4107。保留各职业原有基础数值与传奇搭配。二件对照仅移除两件装备的套装身份，所有装备数值不变。

调用实际 GameEngine.update、自动施法、技能/套装结算、ProjectileSystem碰撞、持续伤害、资源和冷却。去除画面和音频，用同结构无渲染敌人替代 MonsterRig；不另写伤害公式。伤害通过敌人生命扣减统计，包含持续伤害，不重复统计嵌套命中。

输出场景为71层护甲的20秒单个/8个静止首领体型目标，目标在60px圆周，角色做小幅移动以启用移动流派；首领体型更容易吃多段，不能当真实副本DPS。实战为100层、真实怪物与首领AI，统一接近60px后绕圈的简易走位，不使用位移或圣坛。实战有受击与回血；荆棘输出表本身无受击，不包含承伤优势。

## 已修复

- 维尔原先由所有伤害叠加激光层数，陨石等也吃激光增幅；现在仅执政官死光及折射触发、最多60层，每次重新变身重置。形态期间自动施法优先基础死光，遵守玩家手动开关和冷却。四件套由死光逐步升温，不能靠火海立即叠满。
- 四件荆棘原先满血单目标不自动战吼，且战吼使用普通伤害再触发额外荆棘。现在战吼每目标结算一次物理荆棘；攻击附带荆棘共用同一入口，四件增幅统一结算，装备荆棘词缀参与伤害。
- 陨石火海原先每秒重复一整次陨石倍率，持续3秒总量偏高；现在像已有箭雨/黑洞/毒藤一样按持续时间分配总伤害，保留连环陨石的成套质变。
- 连弩实验室原先缺少多数输出流派已有的元素/精英及独立伤害搭配。复用元素嘉年华与斯奎特替换护符/黄道，保留四件套和合法魔盒槽位，不增加隐形职业倍率。

## 一轮公开数值校准

结构修复后的首次同口径测量，单体最高306.35亿/秒、最低4.42亿/秒，相差69.3倍。四件套同时拥有范围、追加命中或暴击机制的流派，不能再全部沿用相近的独立倍率，否则强度预算重复叠加。因此仅定向调整四个离群套装的公开四件增伤，并同步游戏内说明：

| 套装 | 原四件独立增伤 | 校准后 | 保留的质变机制 |
| --- | ---: | ---: | --- |
| 塔拉夏元素 | +800% | +80% | 追加3颗连环陨石 |
| 暗影利刃 | +800% | +200% | 飞刀数量翻倍、返回二次穿刺 |
| 伊纳瑞斯圣骨 | +750% | +200% | 骨风暴范围内同时放大本人和召唤物伤害 |
| 不朽荆棘 | +800% | +300% | 荆棘暴击、战吼全场引爆 |

其余套装保留原有倍率。没有引入隐藏职业补偿或新结算框架。上方表格为这次校准后的唯一最终复测；单体差距收敛到14.0倍，四件/二件最低仍为2.38倍。回归测试用已有15套输出样本同时约束四件质变和最高/最低低于16倍，不追加另一轮全量模拟。

## 判定与范围

15套均能持续合法施法，四件相对二件均有明显输出提升，最强离群已收敛。近身群体、穿透、减速/剧毒条件、叠层速度和承伤能力不同，因此不能只按木桩DPS宣布完全平衡。表中实战验证的是成型档100层可用性，不是150层全部平衡、低等级开荒、所有随机词缀或玩家操作的全覆盖认证。单体偏低的毒镰在8目标合计输出明显提高，维尔需积累死光层数；这些玩法差异保留在数据中。

排查阶段另跑过修复前150层：仅陨石在300秒内通过，其余超时，说明顶层曲线与治疗怪群仍需要独立长期平衡；本轮未把该旧结果冒充最终版本通过记录。没有为了抹平这项差异而给每套添加通用隐藏补偿。

回归用例位于 `tests/build-balance.test.ts`，覆盖十五流派四/二件对照、激光叠层边界、焦点施法尊重手动设置、荆棘单次结算与火海伤害预算。最终统一功能测试与生产构建由主验收记录汇总。
