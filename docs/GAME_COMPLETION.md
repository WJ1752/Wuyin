# 游戏完整度修订与定向验收

日期：2026-11-06。定位为以 150 层秘境为主线的长期刷装游戏。本记录只列本轮实现和实际完成的定向验证；最终构建、统一回归和设备验证由主验收记录汇总。

## 成长与构筑

- 前 15 级保留原节奏：初始 1 点，每升一级获得 2 点，Lv.15 累计 29 点。
- Lv.16 至 Lv.100 再逐步获得 21 点，满级累计 50 点；每职业所有节点升满需 75 点，必须取舍。技能页显示当前预算和下一次获得点数的等级，升级提示按实际增加点数结算。
- 推荐加点先保证当前流派的行动技能，再优先核心与相关分支。免费洗点、等级门槛和父节点要求继续生效，不添加通用职业补偿倍率。
- 旧档超预算时依据当前套装与已有节点稳定迁移；装备、资源和已通关进度保留，版本标记防止重复迁移。演武与历史配装体验也遵守新预算，原历史记录本身保留。

## 秘境变化与轮换挑战

普通 16 层及以上秘境增加按地貌区分的周期地面危险。额外挑战在通关第 16 层后开放，每天按 UTC 零点轮换，即香港时间早上 8 点。挑战使用角色已通关的最高层，不推进普通秘境前沿，也不计入单人职业榜或登峰连胜。

| 模式     | 需要完成的条件                                      |
| -------- | --------------------------------------------------- |
| 追猎契约 | 击败三名精英领队；普通敌人与精英随从不计数          |
| 守望仪式 | 存活时在中央 140 范围内累计驻守 18 秒；离圈暂停充能 |
| 余烬试炼 | 经历六轮已实际爆发的地面危险；只有预警出现不计数    |

三种模式均须在目标完成后击败守关首领。首胜额外获得 1,800 金币、350 碎片与 60 结晶，每个轮换奖励键领取一次；重玩继续结算该场战利品。进入时记录的模式、日期键和层数必须与结算一致，同一场完成回调重放不会再次发放任何收益。

## 操作与战斗反馈

- 荒原狂风的四件套每秒四道龙卷至少有一道追踪近敌；实际施放狂暴冲锋后的四秒内，四道均可追踪。窗口结束恢复原状态。
- 塔格奥毒镰在实际施放血步后的四秒内，死亡镰刀每次毒伤命中多叠一层，继续通过五层瘟疫新星机制获得收益；窗口结束恢复原叠层。
- 战斗与结算提供伤害、承伤、施法次数、技能伤害构成、承伤来源、缺能时间和首领剩余生命比例。伤害统计使用实际生命损失，过量伤害和已被护盾吸收的部分不计为生命伤害。

## 实际完成的验证

本轮六项定向机制回归一次通过，文件为 `tests/gameplay-completion.test.ts`。覆盖实际伤害与过量边界、承伤来源、技能就绪且缺能时的计时与引导免耗、三个挑战的客观门槛，以及两套慢流派手动位移收益的生效与到期。测试在生产 `GameEngine.initHeadless` 初始化的世界中调用实际技能和规则，没有另写伤害或掉落公式。

生产无绘制模式另做三个完整烟测，固定种子 4107，采取靠近至 65 范围后绕圈的走位，不开圣坛、不手动位移。这三例采于本轮最终推荐被动分配修订前，证明生产入口可用，不作为最终配装耗时保证：

| 样本                                  | 实际结果                         |
| ------------------------------------- | -------------------------------- |
| 一级空装游侠，第 1 层                 | 76.7 秒通关                      |
| 当前合法 50 点拉斯玛成型档，第 100 层 | 20.7 秒通关；10 个召唤物正常推进 |
| 当前合法 50 点塔拉夏成型档，第 100 层 | 21.5 秒通关；区域技能正常推进    |

三例均可导出战场帧，未出现绘制适配错误。这些结果证明上述生产模拟入口可用，不代表浏览器画面、手感、真机性能或全部流派已完成实玩验收。

## 新版像素 UI、角色剧情与删除流程

- 营地、系统面板、战斗控件与图标已改为统一的精细像素幻想视觉。营地主界面使用紧凑角色/存档信息栏、独立秘境选层与出征栏，以及装备、技能、旅程、服务四格手机导航；系统面板保留四组入口和组内切换，正文在面板内滚动。
- 新角色流程包含抵达营地与导师引导剧情；剧情可跳过。浏览器验收覆盖新建两名角色、完成抵达/导师流程并进入营地，以及角色删除确认对话框的确认与取消操作。确认删除仅验证了对话框交互，未在浏览器中实际删除角色。
- 角色实际删除由 `tests/accounts.test.ts` 的 8 项用例覆盖；此处不将单测结果描述为浏览器删除验收。

| 浏览器视口 | 已完成的定向检查                                                    |
