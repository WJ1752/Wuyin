# 本地交付验收记录

日期：2026-10-31。实现依据为用户提供的 `1_1.md`；工程从空目录创建。

## 已交付

- React 19 / TypeScript / Vite / PixiJS v8 / Zustand；运行期没有外部素材或后端依赖。
- 5职业、75技能节点、15套装、45传奇、24怪物、8首领、10精英词缀、150层与4地貌。
- 自动施法、六技能栏、键鼠/触控/手柄输入、进度球、血球、四圣坛、哥布林、召唤物和首领阶段行为。
- 多部件角色纸娃娃，8槽换装影响外观；怪物、地面预警、打击特效、装备光柱、小地图与伤害跳字。
- 28种 Web Audio 合成音效、主城/秘境/首领3种动态配乐。
- 装备、技能、魔盒、秘藏、洗练、神铸、宝石、宠物、赛季任务、离线收益和本地远征配装榜。
- IndexedDB 自动存档、JSON 导入导出、坏档原始备份，以及不会覆盖开荒存档的15套成型流派体验。
- 静止、无攻击、无奖励的训练木桩。

## 验收范围

本项目是单机本地实现；远征榜记录本机成绩，没有在线排名或联机服务。未逐层测试150层完整平衡曲线，也未逐设备测量60/120fps。程序化美术与合成音乐为项目实现，不能把功能用例通过等同于商业级画面或与原作逐像素、逐行为一致的认证。

伤害超出安全整数范围时使用BigInt整数比例连乘；生命值和绘图仍采用Number。精确结果可通过 `calculateExactDamage` 读取，界面使用万/亿/兆/京格式显示。

## 功能与视觉补齐（2026-10-31）

本轮根据代码核查中发现的差异修复，并按后续要求改为Q版像素角色风格。沿用现有React、PixiJS、装备身份、战斗区域和怪物攻击判定，不增加独立渲染框架或在线服务。

### 独立视觉配置

- 五职业各一张真实透明PNG，统一Q版像素风，具有不同体型、服装和武器；素材位于 `public/assets/characters`，完整生成提示词见 [CHARACTER_ART.md](CHARACTER_ART.md)。主城、装备预览和战斗共用素材，采用最近邻缩放。
- 75技能各自具有独立语义图形；同一配置用于技能树、详情、战斗栏和施法提示。
- 45传奇、15套装的75个实际护甲部件、普通装备系列与部位组合均有独立图形。唯一性测试忽略颜色与ID，仅比较图形路径，避免用换色冒充独立外观。
- 八个穿戴槽保留独立装备覆盖层；同名装备不同掉落数值共享身份，太古品质不丢失原装备身份。召唤物继续使用程序化骨骼，不复用玩家全身图。

### 已修复行为

- 五种位移读取各自距离与持续时间，支持方向键、摇杆方向和地图边界；以太传送恢复240距离、4秒护盾；冲锋沿途命中击退、血步穿敌治疗、翻滚减速区域、暗影步仅本次必暴。
- 电刑基础3目标；狼人攻速+60%、移速+40%；爪击三连；同次分裂/穿透施法只恢复一次基础资源。
- 修正狂乱、钩爪、诅咒持续时间、飓风破减甲、冻结延长、护盾到期碎裂，以及部分基础技能回能数值。
- 毒镰持续毒伤、瘟疫增幅和腐蚀之牙剩余毒伤结算；莱莲娜计入无尽魂能；木槌倍率及击退；闪电传奇增幅覆盖相应元素。
- 召唤物可受伤、死亡、暂停行动并重生；拉斯玛立即重生和爆炸范围生效；号令骸骨在各召唤物位置触发。
- 无尽深渊为即时、0.2秒、0.4秒三次独立爆炸；亡者大军持续骸骨风暴、小恶魔攻击火星补齐。

## 全场景像素风与分阶段成长（2026-10-31）

本轮按用户要求并行完成，复用 React/PixiJS/Zustand、原有装备身份及存档接口，无新增运行依赖。

- 技能与装备重新绘制为24格逻辑像素图形；保留75技能、45传奇、75套装部件、56普通装备组合的身份与几何唯一性。用同一图形驱动背包、技能树、装备覆盖层与战斗提示。
- 重绘四地貌、营地、怪物家族、八首领专属饰件、哥布林、宠物、召唤物、投射物、范围预警、拾取物和圣坛。共用像素绘图方法，渲染关闭抗锯齿并保持最近邻缩放。
- UI采用硬边面板、像素边框、条块资源显示和共享像素导航图标，保留桌面与手机布局。
- 新角色仅学习一个基础攻击；每级2点、等级门槛、前置2级和逐阶提升由统一数据接口驱动。免费洗点恢复基础攻击的自动施法。旧档迁移保留装备货币，回收不合法分配的技能点；实验室仍隔离。
- 品质分别于4/8/16/31/71层引入稀有/史诗/传奇/套装/太古，层内插值变化。移除旧前3层必掉传奇、5层套装和哥布林固定高级掉落；首领/哥布林/秘藏遵循同一门槛。
- 首通旅程补齐目标套装、检查背包及本轮拾取避免重复；2/4件穿戴成型有明确提示。16层传奇对应本职业首个核心技能，71层太古对应目标流派。秘藏和离线收益使用实际通关进度。

### 本轮验证

- 43项用例均有通过记录：视觉3项单独运行一次，其余39项运行一轮；其中旧难度测试固定要求全程1.16增长，与分阶段曲线冲突，改为验证增长有界且阶段不回落后仅复验该1项通过。最后交叉审查发现结算回调持有可变战利品数组，改为数组副本，新增1项针对性回归并单项通过。
- 类型检查与生产构建通过；修复LootGenerator已归一化品质分支的不可达类型判断。保留Vite既有主包体积提示，未引入额外依赖。
- 浏览器检查：主城、旅程概率、目标套装切换、Lv.1核心技能锁定、失败结算后升至Lv.3获得4点、学习位移扣除1点、后续等级门槛、已学技能加入战斗栏、移动/位移施放、返回营地，以及390px手机旅程弹窗。检查日志无运行错误。
- 浏览器发现通用图标被88%尺寸规则放大，已限制到技能符号容器并复核。初始站桩会被围攻击败，失败仍保留合法收益；需要走位和后续装备成长。
- 数值估算覆盖五职业初始首领输出与31层前代表性装备样本；没有逐层通关150层或测量所有设备帧率。完整长期掉落手感与各流派平衡仍需持续实玩反馈。

## 本地账号、共享仓库与流派实测（2026-10-31）

本轮由账号存档、掉落曲线、战斗流派三个并行任务完成，主任务负责界面、集成及验收；继续使用原有 Zustand、IndexedDB、LootGenerator 和 GameEngine，无新增运行依赖。

- 每个本地账号最多6角色，允许重复职业；角色的等级、技能、资源、背包与进度独立。240格角色背包和480格账号共享仓库分别管理，存取保留物品ID、词条与宝石，不触发自动分解。账号之间隔离。
- 旧存档迁入首个角色。导出包含全部账号、角色和仓库；导入先整体校验，拒绝重复物品ID、非法角色数和损坏装备；旧单角色导入只替换当前角色。重置也仅影响当前角色。
- 保存请求排队避免快速切换丢档；读取IndexedDB与localStorage的最新有效副本，损坏原文留存恢复备份。战斗与演武中禁止角色切换和仓库存取，演武导出仍使用原开荒档。
- 职业专属自然掉落80%属于当前职业，其余四职业各5%；秘藏与指定奖励定向。门槛品质低概率引入后平滑上升。固定种子4万次自然掉落和150层概率曲线结果见 [掉落报告](LOOT_BALANCE.md)。
- 15套流派复用真实战斗更新、自动施法、资源、冷却、投射物及AI进行模拟，修复死光叠层、荆棘重复结算、火海预算与连弩配装，并按实测公开调整离群套装数值。具体口径、表格和限制见 [BD报告](BUILD_BALANCE.md)。

浏览器在独立的本地5177端口验收，未改动用户其他端口存档。确认创建第二角色、新账号隔离、法师秘藏装备存仓再由游侠取出、货币独立、刷新后装备不丢失/复制、演武仓库禁用、训练进出与恢复营地。390px手机角色名册无横向溢出；检查期间浏览器没有error日志。截图：[角色名册](accounts-preview.jpg)、[手机角色名册](accounts-mobile.jpg)。

设计参考：《迷雾大陆》研发团队介绍强调传奇、职业套装驱动构筑，见 [官方介绍](https://www.taptap.cn/app/635596/all-info?platform=pc)；《元气骑士前传》官方介绍了背包分类、仓库入口与战斗期间功能限制，见 [SS0优化说明](https://qz.chillyroom.com/da/article/base/141)。本项目的6角色上限、容量、80/20职业权重与具体套装倍率是本轮设计，不冒充原作数值。

当前账号为单机本地档案，没有密码认证与跨设备云同步。固定场景平衡验证不替代长期刷装、全部150层手动通关或所有设备性能验收。

最终验证：统一运行57项测试，56项首次通过；1项数据快照仍锁定校准前四件倍率，按公开数值更新后仅单项复验通过，57项均有通过记录，没有重复全量测试。`pnpm build`中的TypeScript检查与Vite生产构建通过；保留原有主包超过500KB提示（当前主包约272KB gzip）。15套固定实战全部通过100层，四件/二件提升2.38–13.83倍；单体最大差距由69.3倍收敛至14.05倍，仍保留群体、控制和生存定位差异。
