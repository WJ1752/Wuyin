# 五职业像素角色素材

2026-10-31，按用户指定的《元气骑士前传》像素风方向，使用内置 image_gen 为五职业分别重新生成原创 Q 版角色；没有使用现有游戏素材，也没有对原写实图做像素化滤镜。当前版本覆盖了先前的写实初稿。

素材保留生成器输出的透明 PNG，位于 `public/assets/characters/<classId>.png`，主城、装备预览与战斗共享同一素材；装备纹章与武器层复用 PixiJS 纸娃娃框架。使用大头短身、阶梯轮廓、方块像素簇及职业限定配色。生成器输出画布为 1254×1254；提示词的 64×64 指逻辑像素风格目标，不是文件分辨率。
