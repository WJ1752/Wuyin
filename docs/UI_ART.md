# 像素幻想界面美术

## 视觉方向

界面采用精细像素幻想风格：深蓝石板与夜色作为底色，暖金用于重要操作和标题，青绿色用于状态反馈。按钮、图标和边框使用清晰的像素边缘，不加模糊滤镜；重要操作保持足够的触控面积，手机布局优先保证单列阅读。

## 按钮与面板材质

`pixel-kit-source.png` 是四格材质图，脚本按以下位置提取并裁切透明边缘：

- 左上：`pixel-primary.webp`，重要操作按钮的暖金主态。
- 右上：`pixel-secondary.webp`，次要按钮和一般操作。
- 左下：`pixel-slot.webp`，战斗技能栏槽位。
- 右下：`pixel-panel.webp`，弹窗及大型面板的九宫格边框。

按钮通过 CSS `border-image` 将对应边角固定并拉伸边缘与中心，避免整体缩放造成角部变形。主操作和次操作使用各自材质，禁用态、聚焦态仍需保持文字清晰与键盘可见焦点。面板材质用于边框，不应把内部内容挤入边缘区域。

## 重新处理资产

在仓库根目录运行：

```sh
npx tsx scripts/prepare-ui-art.ts
```

脚本读取 `docs/art/ui-v3/` 中的七张原图，并写入 `public/assets/ui/`。它会验证材质图是带 Alpha 通道的正方形偶数尺寸图片；四格材质裁切透明边缘后无损转为 WebP，导航图使用最近邻方式缩放到 1280 × 1280 并无损转码，职业技能图缩放到 1280 × 1280 并以 WebP 质量 92 转码。运行结束时会输出材质图集的尺寸与透明通道信息。

图集格子的顺序是资源接口的一部分。替换图片时需保持相同的格数、行列顺序和透明背景，或同步更新消费该图集的坐标映射。

## 生成提示词规范

以下是按本轮生成要求归纳的提示词规范，不是原始提示词的逐字记录，也不声称还原了每张原图的完整 prompt：

- 统一描述为精细像素幻想风格，使用深海蓝石板、旧银与暖金，并以青绿宝石色作点缀。
- 明确要求锐利的方形像素（sharp square pixels），保持固定等距网格；边缘和细节对齐网格，不使用模糊、抗锯齿或平滑渐变。
- 明确要求无文字、无字母、无标记和无水印（no text / no watermark）。
- 输出透明 RGBA 图集，并严格维持固定格数和单格边界：界面材质为 2 × 2，导航图标为 4 × 4，职业图标为 4 × 4（15 个技能主题加 1 个职业徽记）。
- 图集的每个格子只放一个完整、居中的主题，四周留出安全间距；不得让主体越过格线或依赖跨格装饰。

后续生成时应把图集尺寸、透明背景、网格、格子数量和顺序作为硬约束写清楚，再描述该图集内的主题内容。生成完成后检查 Alpha、尺寸、格线对齐、格子数量和无文字要求，再运行处理脚本发布。
