# 《雾隐》重审与验收

2026 年 11 月 21 日

## 重审结论

现有战斗和养成足以支撑一条完整主线。生产战斗引擎的首关样本中，五个一级空装职业都通过了第 1 层。项目已有装备、技能、首领、地图、联机和存档接口，可以用它们把剧情、整备和战斗接成闭环。

| 审查发现 | 处理 |
| --- | --- |
| 开场剧情在首胜后中断，150 层轮转缺少明确的故事终点 | 主线追踪五道章关，终章有专属首领、结算、插画和可重读的结局。第 51–150 层保留为高阶远征 |
| 速通可能跳过下一章，营地只显示通用导航 | 速通在下一道未完成的章关停下。营地提示可执行的整备或出征，旅程页给出首领打法和可进入的层数 |
| 战斗 HUD 隐藏了开局提示和契约目标，近身 AUTO 可能在打不到时消耗资源 | 恢复战斗目标与计数，按技能的有效范围决定自动施法。保留手动施法和远程词条触发 |
| 快速穿戴只补空槽，容易继续使用低攻击武器 | 结算提供更高基础攻击武器的比较入口，沿用装备详情，玩家决定是否更换 |
| 云端不可用时，单人入口和关窗受离队请求阻塞 | 本机菜单与主动离队分开。房间、奖励分别加载。回营重连保留托管战斗，离队按本次远征匹配 |
| 单人结算只等待定时存档，刷新后普通远征可能继承旧的契约状态 | 结算立即安排保存，进入普通远征及训练时清除未恢复的契约状态。云端已入账的奖励独立于浏览器备份状态 |
| 营地、HUD 和战场的主次色割裂，地表纹理与战斗特效争抢视线，剧情结尾缺少自己的画面 | 沿用暮铁守望的石材和青铜，将暖金用于出征与章关，四地貌保留独立冷暖色。调整地表色阶，章关增加铜灯镶嵌，通关后营地灯火变暖 |
| 全屏布局已随设备适配，旧方向选项仍显示但无法切换画幅 | 界面随窗口方向适配，旧档的方向字段继续兼容 |

## 游玩样本

生产 `GameEngine.initHeadless` 使用固定种子，一级空装野蛮人沿荒原狂风方向成长。营地种子为 7715。每场按现有刷装脚本的策略选择装备、推荐加点、优先神铸武器，并使用定向秘藏与魔盒。战斗靠近后绕圈，使用自动施法。

| 项目 | 结果 |
| --- | --- |
| 第 1 / 8 / 16 / 31 / 50 层战斗用时 | 36.2 / 27.4 / 27.7 / 20.8 / 21.0 秒 |
| 第 1 层至主线结局 | 19 场，累计模拟战斗 7 分 56 秒 |
| 失败与回刷 | 均为 0 |
| 最终成长 | Lv.14，武器神铸 +23，解锁至第 53 层 |

样本只计战斗时间。真人需要额外阅读、比较并操作装备和技能，其进度取决于走位、掉落和整备选择。完整开荒只抽样了一个流派和固定种子。

## 发布验收

- `pnpm build` 通过，包含前后端类型检查。生产入口主包约 329 KB gzip，Vite 仍提示主块压缩前超过 500 KB。
- 一轮 `pnpm test` 共 120 项全部通过，覆盖章关速通、旧档兼容、近身 AUTO、联机领奖、过期离队请求和既有成型配装回归。
- 桌面 Chromium 1260 × 800 从全新访客创建魂灵师，读完开场，进入第 1 层，暂停并恢复战斗，击败守墓君王后阅读战报。隐藏并恢复营地提醒，刷新后在旅程中看到已完成章关。
- Chromium 模拟手机 390 × 844，使用低等级高层测试档验收落败、清除上次未完成的契约状态和回营武器比较。另一份 49 层存档使用成型配装进入真实第 50 层战斗，结算后打开归灯插画，刷新后重读结局并手动选层进入第 51 层。手机档案属于定点验收，完整开荒见上节。
- 使用本机内存服务器注册测试账号，阻断队伍状态、奖励与离队接口后仍可关闭选层面板并单人进战。恢复队伍状态接口后，启动一人托管远征，在奖励接口仍不可用时刷新并重连同一场远征。浏览器检查无未捕获异常。

基线的单次生产包实验使用 390 × 844 Chromium、冷缓存、4 Mbps 下载、120 ms RTT、4 倍 CPU 降速和未启用压缩的本机 Fastify。选角约 6.3 秒可用，跳过序幕后约 7.0 秒营地就绪，点单人出征约 7.7 秒后可控。首战可控前页面 Resource Timing 至少记录 7.69 MB。战斗约 10 秒墙钟只推进了约 7 秒游戏倒计时。源站压缩、设备 GPU 和公网传输需要在实际发行环境测量。

本轮交付范围是像素重绘、界面重新布局、动效、音频与其直接相关的呈现缺陷。营地图由 2,820,370 B 降到 668,864 B，选角阶段移除营地图片的高优先级预加载。战斗镜头限制在地表范围内，缺失资产返回可识别的 404。治疗瓶和进度晶石改用不同轮廓，危险描边移到普通特效上方，色弱辅助也应用到战场。参考 [Xbox 游戏无障碍指南](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/103)。

动作与图集的范围、生成方式和落盘路径见 [整体美术方案](ART_DIRECTION.md)。

### 像素版实装验收

- `pnpm build` 通过前后端类型检查和生产打包。入口 JavaScript 约 330 KB gzip，仍有主块超出 Vite 体积提示的记录。
- 14 项定向测试通过，覆盖战斗镜头、触控布局、营地坐标、透明图集、外观身份和主动技能声效映射。
- 390 × 844 Chromium 从访客选角进营，角色名和确认按钮都在首屏。走动时加载独立跑动姿势，切换系统减少动态时，营地雾、灯光和传送门的循环动效停止。单人战斗实测脚步、弓弦与命中声，走到战场北边界时，场景铺满画布，角色仍在状态栏下方完整可见。
- 1440 × 900 Chromium 核对装备、技能和主线结局页面。使用独立内存服务器注册并迁移测试角色，启动托管远征和第 150 层官方试炼，验证客户端收到战斗状态后调度声效。缺失图片返回 404，验收流程无浏览器未捕获异常。

在上述同一限速配置下，首战可控前记录的资源传输从约 7.69 MB 降到 2.32 MB。选角就绪从约 6.3 秒降到 4.3 秒，跳过序幕后营地等待从约 7.0 秒降到 1.9 秒，单人出征点击到可控从约 7.7 秒降到 4.7 秒。战斗十秒样本的第 95 百分位帧间隔从 116.6 ms 降到 50.1 ms，新版倒计时推进了十秒。两版各采样一次，真机持续战斗与公网联机仍是独立发行门槛。
