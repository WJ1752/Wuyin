# 《雾隐》重审与验收

2026 年 11 月 21 日

## 满包时的整备体验

用含七种品质、八个部位和异职业武器的 240 件装备存档复查。旧版手机首件位于 y=550，查看末件时，筛选栏已在视口上方约 8,247 像素。桌面也会把未使用的详情栏留空。

新版一页 24 件，默认按最近入包排列，可按等级、品质、基础攻击或护甲排序。搜索支持装备名、部位、职业和词条的组合，例如「主手武器 暴击率」。点角色的空槽会带出本职业可穿的同部位装备。在详情中可以对照穿戴前后的面板数值，换装会激活或失去的二件、四件套效果也列入预览。

批量整理可跨页勾选，同一次操作只作用于当前筛选结果。仓库容量不足时会保留整批选择，方便减少件数。分解前会列出实际件数和所得结晶，沿用铁匠的珍稀装备、刻印底材和词条保护。手动锁定的装备可正常穿戴和存取，锁随装备保存，同时保护单件分解、批量分解、魔盒萃取和用作刻印素材。

一轮 131 项自动测试全部通过。桌面 Chromium 在 240/240 满包状态验收了分页、键盘找装、换装预览与实际面板一致、旧装返包和锁跨刷新保留。仓库只剩一格时尝试存两件，全部留在背包，取消一件后可正常存入。分解样本中，取消保留了全部五件，确认后只消耗一件普通装备，获得 4 结晶。390 × 844 触控模拟中首件从 y=550 提前到 y=381，第十页点开详情再返回仍定位到同一件。见[桌面装备对比](backpack-desktop.webp)和[竖屏行囊](backpack-mobile.webp)。

**开荒样本。** 从一级空装野蛮人开始，沿裂嶂风裔构筑，用生产引擎战斗和真实结算、穿戴、锻造、掉落接口打通第 50 层。种子 7715，共 19 场，0 次失败，累计模拟战斗 8 分 23 秒。五道章关用时依次为 41.50、27.90、17.57、21.83、21.43 秒。165 件战场掉落全部进入结算，角色最终 Lv.14，解锁至第 53 层。脚本时间只累计战斗，真人的阅读、整备和决策另计。

**本地发行检查。** 桌面 Chromium 从全新访客创建魂灵师，26.4 秒打通首关，领取战利品、读战报、装备物品、学习技能并刷新验档。390 × 844 触控模拟检查了传奇详情和横向溢出。第 50 层使用成熟角色定点档，在战场激活圣坛并通关，打开结局，重新载入后重读并进入第 51 层。职业榜成功向服务器查询初版归档。

**游侠实机。** [约 30 秒的有声录像](Wuyin-Release-Gameplay.mp4)使用预置的 11 级游侠、正式构建及浏览器键鼠输入自动操作。前半段展示营地、异职业装备限制、换手弩和技能页，约第 14.5 秒进入「余烬铸灯」，本场击败 33 个敌人并通关。视频为 1280 × 800、60 fps 编码，音轨取自同一局游戏。第 15 至 27 秒的原始录屏里有 670 张不同的连续画面，实测约 55.8 帧/秒。这个测量描述本机录屏表现。

**加载与回归。** 桌面进营不请求战斗模块，进入训练场才加载一次并创建画布。入口 JavaScript 从约 346 KB 降至 185 KB gzip，按需战斗模块约 161 KB gzip。生产构建和前后端类型检查通过，两个模块压缩前仍超过 Vite 的 500 KB 提示线。一轮共 129 项测试中，更新旧套装名和缓冲施法计数的两处断言后，定向复验通过。收尾复验操作、技能行为和主线的 31 项测试全部通过。

**仍需发行验证。** 五个故事章关之外，普通楼层以地貌、敌群和数值组合为主。中高端桌面与模拟手机不能覆盖真实低端安卓、iOS 的温升或触控手感。外部玩家的盲测、公网 HTTPS 四人跨网长局和容量，以及发行资产授权的独立核验尚待完成。

## 前一轮主线重审

现有战斗和养成足以支撑一条完整主线。生产战斗引擎的首关样本中，五个一级空装职业都通过了第 1 层。项目已有装备、技能、首领、地图、联机和存档接口，可以用它们把剧情、整备和战斗接成闭环。

| 审查发现 | 处理 |
| --- | --- |
| 开场剧情在首胜后中断，150 层轮转缺少明确的故事终点 | 主线追踪五道章关，终章有专属首领、结算、插画和可重读的结局。第 51–150 层保留为高阶远征 |
| 速通可能跳过下一章，营地只显示通用导航 | 速通在下一道未完成的章关停下。营地提示可执行的整备或出征，旅程页给出首领打法和可进入的层数 |
| 战斗 HUD 隐藏了开局提示和契约目标，近身 AUTO 可能在打不到时消耗资源 | 恢复战斗目标与计数，按技能的有效范围决定自动施法。保留手动施法和远程词条触发 |
| 快速穿戴只补空槽，容易继续使用低攻击武器 | 结算提供更高基础攻击武器的比较入口，沿用装备详情，玩家决定是否更换 |
| 云端不可用时，单人入口和关窗受离队请求阻塞 | 本机菜单与主动离队分开。房间、奖励分别加载。回营重连保留托管战斗，离队按本次远征匹配 |
| 单人结算只等待定时存档，刷新后普通远征可能继承旧的契约状态 | 结算立即安排保存，进入普通远征及训练时清除未恢复的契约状态。云端已入账的奖励独立于浏览器备份状态 |
| 营地、HUD 和战场的主次色割裂，地表纹理与战斗特效争抢视线，剧情结尾缺少自己的画面 | 沿用暮铁守望的石材和青铜，将暖金用于出征与章关，四地貌保留独立冷暖色。调整地表色阶，章关增加铜灯镶嵌，通关后营地灯火变暖 |
| 全屏布局已随设备适配，旧方向选项仍显示但无法切换画幅 | 界面随窗口方向适配，旧档的方向字段继续兼容 |

## 游玩样本

生产 `GameEngine.initHeadless` 使用固定种子，一级空装野蛮人沿荒原狂风方向成长。营地种子为 7715。每场按现有刷装脚本的策略选择装备、推荐加点、优先神铸武器，并使用定向秘藏与魔盒。战斗靠近后绕圈，使用自动施法。

| 项目 | 结果 |
| --- | --- |
| 第 1 / 8 / 16 / 31 / 50 层战斗用时 | 36.2 / 27.4 / 27.7 / 20.8 / 21.0 秒 |
| 第 1 层至主线结局 | 19 场，累计模拟战斗 7 分 56 秒 |
| 失败与回刷 | 均为 0 |
| 最终成长 | Lv.14，武器神铸 +23，解锁至第 53 层 |

样本只计战斗时间。真人需要额外阅读、比较并操作装备和技能，其进度取决于走位、掉落和整备选择。完整开荒只抽样了一个流派和固定种子。

### 像素版实装验收

- `pnpm build` 通过前后端类型检查和生产打包。入口 JavaScript 约 330 KB gzip，仍有主块超出 Vite 体积提示的记录。
- 14 项定向测试通过，覆盖战斗镜头、触控布局、营地坐标、透明图集、外观身份和主动技能声效映射。
- 390 × 844 Chromium 从访客选角进营，角色名和确认按钮都在首屏。走动时加载独立跑动姿势，切换系统减少动态时，营地雾、灯光和传送门的循环动效停止。单人战斗实测脚步、弓弦与命中声，走到战场北边界时，场景铺满画布，角色仍在状态栏下方完整可见。
- 1440 × 900 Chromium 核对装备、技能和主线结局页面。使用独立内存服务器注册并迁移测试角色，启动托管远征和第 150 层官方试炼，验证客户端收到战斗状态后调度声效。缺失图片返回 404，验收流程无浏览器未捕获异常。

在上述同一限速配置下，首战可控前记录的资源传输从约 7.69 MB 降到 2.32 MB。选角就绪从约 6.3 秒降到 4.3 秒，跳过序幕后营地等待从约 7.0 秒降到 1.9 秒，单人出征点击到可控从约 7.7 秒降到 4.7 秒。战斗十秒样本的第 95 百分位帧间隔从 116.6 ms 降到 50.1 ms，新版倒计时推进了十秒。两版各采样一次，真机持续战斗与公网联机仍是独立发行门槛。
